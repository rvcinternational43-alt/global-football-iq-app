# Global Football IQ — Starter ZIP

A free static football prediction website starter with responsive prediction cards, market filters, single-pick selection, accumulator probability calculation, and a browser-local results tracker.

IMPORTANT: Fixtures and percentages are illustrative sample data, not real predictions. There is no live fixture feed, model, backend, login, or cloud database. Results are saved only in the current browser. Combined probabilities multiply individual probabilities and assume independence, which may be misleading for related markets. No system can guarantee 99% football wins.

## Run locally
Extract the ZIP and open `index.html` in a browser.

## Free hosting
Upload `index.html`, `styles.css`, and `app.js` to a GitHub repository and enable GitHub Pages in repository Settings.

## Before using real matches
Connect a permitted football fixture/results provider, replace sample data in `app.js`, and validate probability estimates against historical out-of-sample results. Never expose private API keys in frontend JavaScript.
